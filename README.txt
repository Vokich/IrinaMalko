САЙТ-ВИЗИТКА ИРИНЫ АЛЕКСАНДРОВНЫ МАЛЬКО
======================================

КАК ОТКРЫТЬ
Дважды нажмите на файл index.html. Он откроется в браузере.
Работа сайта не требует сервера, подключения к базе данных и сборки.
Для подгрузки шрифтов из Google Fonts нужен интернет; без интернета используются системные шрифты.

КАК РАЗМЕСТИТЬ В ИНТЕРНЕТЕ
1. Распакуйте архив.
2. Загрузите файл index.html и папку assets на хостинг в одну директорию.
3. Назначьте index.html главной страницей.

ФАЙЛЫ
index.html                 — вся страница, стили, анимация и мобильное меню
assets/irina-malko.webp    — оптимизированная фотография
assets/irina-malko.vcf     — карточка контакта для скачивания
assets/favicon.svg         — иконка вкладки браузера
